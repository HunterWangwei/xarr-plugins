# XArrPay 币安ID收款插件

通过币安官方接口 [`GET /sapi/v1/pay/transactions`](https://developers.binance.com/docs/pay/rest-api/Get-Pay-Trade-History) 轮询币安 Pay 到账记录，按递增金额自动匹配订单。

## 安装

在应用商店里添加[应用源](../../README.md#应用源链接)，然后安装「币安ID收款」。手动安装也可以：把 `binance_pay/` 目录上传到 XArrPay 程序目录的 `plugins/pay/` 下，再重启程序。要求 XArrPay 版本不低于 1.5.1.9。

## 配置

1. 在币安的 API 管理里创建一个 API Key，**只勾选「读取」权限**，并绑定服务器 IP。
2. 在后台添加通道账号，填写收款币安ID、API Key/Secret、收款币种和汇率。如果你的订单本身就以 USDT 计价，汇率填 1。
3. 「收款码内容」可选。填了就展示收款二维码，不填就展示币安ID和金额。

## 流程

1. 下单时，订单金额 ÷ 汇率 = 应付币数，然后由框架的递增金额规则让每笔待支付订单的金额都不一样，例如 10.00、10.01。
2. 定时任务每 20 秒拉取一次最近 N 分钟的收入记录。拿到记录后先按 transactionId 去重，再入库并上报，框架按金额匹配订单。
3. 如果接口返回 -2014 或 -2015（Key 无效、没有权限、IP 不在白名单），插件会自动把账号下线。

## 注意

- 金额精度是 0.01。用户必须按页面显示的金额原样转账；多付的零头会被舍去，照样能匹配订单。
- 接口每次调用占 3000 权重，按 UID 计算。如果改小 `crontab` 的间隔，注意不要超出限频。
- 币安 API 在国内无法直连，服务器需要有海外网络。
